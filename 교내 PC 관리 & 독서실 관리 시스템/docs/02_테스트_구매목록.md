## 구매 전 확인할 점

- **버전 선택(판매 페이지의 6가지 버전표 기준)**: Type 3 = 24G 레이더 + Zigbee2MQTT용, 거치대 없음(Smart Life 앱 사용 불가). Type 5 = Type 3 + 거치대. Type 4, 6은 Tuya 전용으로 Tuya 게이트웨이가 필요해 쓸 수 없고, Type 1, 2는 PIR 센서입니다. 제목에 PIR·온도·습도 같은 단어가 있는 것은 같은 페이지에 다른 버전이 함께 있기 때문입니다.
- **판매 페이지 사양표로 확인한 것**: 전지 CR2450 DC3V, 감지 거리 5m 이하, 감지 각도 120°, Zigbee 3.0, 동작 온도 -10~55℃, 크기 33×33×16mm(33×33×26mm, 38×38×16mm도 병기됨). 리뷰와 설계안(지름 3.3cm, 두께 1.6cm)의 수치와 일치합니다. 세 가지 크기 중 Type 3에 해당하는 것은 표에 표시되어 있지 않습니다.
- **모델 번호는 미확인**: 모델 번호(ZG-204ZP)는 표시되지 않았습니다. 주문 전에 판매자에게 문의하거나, 받은 뒤 제품 라벨과 Zigbee2MQTT 인식(`ZG-204ZK`(HOBEIAN)로 보일 수 있음)으로 확인하세요.
- **국내 판매처**: ZG-204ZP를 정확한 모델명으로 파는 국내 쇼핑몰은 찾지 못했습니다. 다나와의 비슷한 Tuya 24GHz 센서 2건(26,210원, MOES 36,750원)은 모델명·전원 방식이 확인되지 않았고, 이런 제품에는 USB 5V 전원형이 많아 설계안의 무배선 조건에 맞지 않을 수 있습니다.
- **불량 가능성**: 리뷰 댓글에 작동 불량·간섭, 환불 사례가 있어 **예비 1개**를 포함했습니다 (검증되지 않은 후기).
- **배터리**: 판매 페이지 사양표에서 CR2450 DC3V를 확인했습니다. 리뷰에서는 전지가 기본 장착되어 있는 것으로 보이며 예상 수명은 약 8개월입니다(미검증). 예비 전지는 교체 시험용입니다.
- **동작 특성**: 설정 반영 최대 10분, 배터리 잔량 보고 최대 24시간, 사람 없음(`false`)은 `fading_time` 이후 전송됩니다.
- **정확도**: 리뷰에서 4.5m 부근 오탐지(미감지)가 있었고, 커튼 같은 움직임에 반응할 수 있습니다. 설계안의 감지 거리 약 0.75m 이내 설정은 현장에서 확인해야 합니다.
- **동글 펌웨어**: ZBDongle-P는 Z-Stack 코디네이터 펌웨어가 설치된 상태로 출하된다고 합니다. 받은 뒤 Zigbee2MQTT에서 인식되는지 확인하세요.
- **조회하지 못한 곳**: 디바이스마트, 아이씨뱅큐, 엘레파츠 등 국내 부품 쇼핑몰은 검색으로 가격을 확인하지 못했습니다. 이곳에서 판매하면 직구보다 빠를 수 있으니 구매 전에 직접 조회하세요.
