# 교내 스마트 PC 통제 & 독서실 관리 시스템

학교 로컬 네트워크에서만 동작하는 학생 노트북 통제와 독서실 좌석 관리 시스템입니다.
전체 설계는 [docs/00_최종설계안_원본.txt](docs/00_최종설계안_원본.txt)를 참고하세요.

## 구성

| 폴더 | 역할 | 비고 |
|---|---|---|
| `server/` | 교사용 중앙 서버. 좌석 상태머신, 스케줄/블랙리스트 API, Zigbee2MQTT 구독 | 독서실 허브 PC에서 실행 |
| `agent-service/` | `SchoolService` (Windows 서비스). 프로세스/사이트 감시, 시간 조작 방어 | 학생 노트북 |
| `portal/` | `SchoolPortal` (C# + WebView2). 예약/입실/외출/퇴실/빈자리 신고 GUI | 학생 노트북 |
| `kiosk/` | 입구 전광판. 4자리 입실 코드, 터치 입퇴실, 신고 현황 | 입구 공용 PC |
| `shared/` | 서버와 클라이언트가 공유하는 메시지/모델 정의 | |
| `tools/netcheck/` | A안(교내망 직결) 접속 테스트 도구. PowerShell/CMD 버전(파이썬 불필요)과 파이썬 버전 ([사용법](tools/netcheck/README.md)) | 허브 PC, 교무실 PC, 노트북 |
| `examples/` | 학생용 파이썬 예제와 테스트 (좌석 상태머신, MQTT, 로그인 API, 프로세스 감시) ([사용법](examples/README.md)) | 개발 PC |
| `docs/` | 설계 문서, 센서 현장 테스트 기록, [테스트 구매 목록](docs/02_테스트_구매목록.md) | |

## 진행 순서 (위험한 부분부터 검증)

1. [ ] 센서 현장 테스트: SONOFF Dongle Plus-P, Zigbee2MQTT, ZG-204ZP 좌석 2~3개
2. [ ] 서버 좌석 상태머신 (가짜 센서 신호로 단위 테스트)
3. [ ] 전광판 + 포털 GUI (인증코드 발급과 입실 흐름)
4. [ ] 노트북 서비스 (차단, 스케줄, 시간 방어). 자기 보호 기능은 마지막에 추가
